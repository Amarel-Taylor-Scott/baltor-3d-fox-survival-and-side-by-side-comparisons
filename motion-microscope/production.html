Two 48-second view studies

The Motion Microscope follows the supplied fox's Walk clip. A Trace of Motion follows Run, with mint front-foot and apricot tail-tip histories. All four panels use the same deterministic animation time. The model reports each panel's actual bone-pose fingerprint; capture rejects any mismatch.

Designed to compare

A fixed 2×2 layout keeps surface, wireframe, skeleton and profile visible throughout. Stable orthographic cameras, restrained petrol/mint framing, projected joint markers and a shared clock keep the animation central. The running film adds sampled bone histories. The scene marks its slow-motion and 24–28-second freeze segments.

Run locally

cd visual-labs/motion-microscope
npm.cmd test
npm.cmd run serve
# http://127.0.0.1:8798/output/review.html
# Interactive: http://127.0.0.1:8798/?episode=trails

powershell -File run.ps1 -Mode pilot -Episode microscope -Out output/new-pilot
# Inspect contact sheet and individual frames, then add visual-review.json.
powershell -File run.ps1 -Mode render -Episode microscope -Out output/new-film -Pilot output/new-pilot

Rendering needs an installed Chrome, Playwright, Sharp, FFmpeg and FFprobe. The wrapper uses the project's known-good local FFmpeg path; set FFMPEG_PATH and FFPROBE_PATH elsewhere. It does not install packages or change system settings. Every capture uses a fresh output directory and a matching source-locked visual pilot.

Assets and narration

Rig, animation and local license texts are pinned in the asset manifest. The Mesh2Motion project identifies its art assets as CC0 and platform code as MIT. This study uses its existing fox rig and clips, not a new auto-rigging export.

The narration packages contain local Kokoro stock-voice audio, synthesis provenance and measured sentence cues. They do not claim word-level alignment or lip sync. Existing model files and the isolated narration runtime remain in the sibling character-explainer/audio-tooling folder.

Verification boundaries

  • Source and media hashes establish the exact revision tested.
  • Actual browser rig checks establish deterministic skin animation and four-view pose agreement.
  • Every captured frame must pass synchronization and layout-warning gates.
  • Encoded MP4 checks include H.264, 1080×1920, 30fps, 1,440 decoded frames, BT.709, one AAC narration track, full decode and browser seeking/playback.
  • Sampled visual review is recorded separately. It is not an all-frame aesthetic review or human listening approval.
  • Trails are in-place animation bone histories, not physical footprints, measured forces or real travel.
  • These are local review artifacts. Nothing is uploaded, scheduled or published.
